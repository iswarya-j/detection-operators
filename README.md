Point, Edge & Line Detection using OpenCV
This project performs Point Detection, Edge Detection, and Line Detection on an input image using OpenCV.
🚀 Techniques Used
Point Detection: Laplacian Filter
Edge Detection: Prewitt Operator, Sobel Operator
Line Detection: Canny + Hough Transform
🛠 Requirements
Install dependencies:
Bash
pip install opencv-python numpy
▶️ Run the Code
Bash
python main.py
Enter the image path when prompted.
📌 Output
The program displays results for:
Grayscale & Blurred image
Laplacian Point Detection
Prewitt and Sobel Edge Detection (Gray & RGB)
Line Detection using Hough Transform
